# English

## Age Calculator

A simple C# console application that takes the user's birth year and calculates their age based on the current year.

### Works
1. Enter your birth year.
2. The program automatically fetches the current year (`DateTime.Now.Year`) and prints your age.



# Deutsch

## Altersrechner 

Eine einfache C#-Konsolenanwendung, die das Geburtsjahr des Benutzers abfragt und das Alter anhand des aktuellen Jahres berechnet.

### Funktionsweise
1. Geben Sie Ihr Geburtsjahr ein.
2. Das Programm ruft automatisch das aktuelle Jahr (`DateTime.Now.Year`) ab und gibt Ihr Alter aus.
